# Exact-source wheel batching

2026-11-14. Uses the existing committed `car-concept.glb` and `car-traffic.glb`; no downloaded or altered asset. Existing source attribution remains unchanged. See [car-wheel-repair.md](car-wheel-repair.md) for the canonical axle, tyre contact and caliper repair.

The native `canada-upper-before-city-profile.json` recorded 408 beauty calls and 455,952 triangles across Rim1, Rim2, Brake, Disc, Tireside and Tiretread. Both source models contain four wheels with these six opaque materials. Traffic simplification reduced triangles but retained all 24 wheel primitives. This change targets submission count, not geometry detail or view distance.

`buildDetailedCarTemplate` now clones each identical source wheel material once, using object identity rather than a name match. `cloneDetailedCar` still gives each car its own material clones. After car creation, the capability-gated adapter packs four distinct canonical geometries into each of six BatchedMeshes. It does not assume left/right or front/rear geometries are interchangeable. Unsupported renderers keep the original 24-mesh draw hierarchy.

The existing steer and spin groups remain in place after draw meshes detach. Actors.sync updates their rotations as before, then the adapter derives car-local instance matrices from those retained node chains. Brake pads/calipers follow only the steer carrier. Tyres, rims and discs follow the spinning hub. Canonical positions, rolling radius, angular-speed calculation, road clearance and collision are unchanged. Aggregate bounds update after steering; Three independently culls each original wheel part for camera and shadow views.

Packed geometry is cached by the ordered source geometry identities and remains immutable. Measured packed vertex/index storage is 2,354,632 bytes for the concept model and 881,840 bytes for traffic, shared across cars of the same template. Each car owns its batch instance matrices, culling bounds and materials. Construction briefly allocates packing buffers before reusing cached geometry on subsequent cars; this is not a zero-allocation creation path. Shared packed resources have template/session lifetime, matching current vehicle-template lifetime; future per-car disposal must not dispose those shared buffers while another car uses them.

Targeted tests load both actual GLBs through GLTFLoader, preserving source material identity and interleaved attributes while replacing browser image decoding with empty textures. They verify all attribute components and indices, transformed vertices under steering/spin/root rotation, independent clone transforms, nonrotating calipers, physical radius/contact, unsupported fallback, idempotence and per-wheel camera/shadow culling. Wheel totals remain 65,240 triangles for concept and 18,588 for traffic. Five targeted tests and TypeScript passed.

A fully visible car changes from 24 wheel meshes to six multi-draw batches. The main caller passes `renderer.extensions.has("WEBGL_multi_draw")` to the optional second Actors constructor argument, which defaults to false.

Native isolated-car attribution verified 24 to six calls in both beauty and shadow passes, preserving 65,240 wheel triangles per pass. The camera had the same yaw/pitch/FOV and differed by 8.1 cm in position. Ordinary approach driving/steering/braking, exit and the parked-wheel appearance were inspected. Evidence: `artifacts/local/canada-wheel-native-comparison.json` and before/after parked images/profiles. This makes no whole-game FPS or universal pixel-equivalence claim.
