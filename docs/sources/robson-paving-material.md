# Robson garden paving material — 2026-11-16

## Deficiency and reference

The existing main garden substrate in `robson-square.ts` uses the citywide `Materials.concrete` texture, `concrete_pavement`, at world X/Z divided by four. Native `artifacts/local/robson-circulation-whole-final.jpg` shows broad, dark irregular slab marks dominating the walking foreground. The current material is shared with unrelated city paths, so changing that instance would exceed this local task.

The cached [TCLF Robson Square reference](https://www.tclf.org/landscapes/robson-square), including Charles A. Birnbaum's [2019 photograph 060](https://www.tclf.org/sites/default/files/styles/full_width/public/thumbnails/image/CANADA_BritishColumbia_Vancouver_RobsonSquare_byCharlesABirnbaum_2019_060_sig_006.jpg), shows comparatively fine rectangular paving rows across the upper terraces. TCLF identifies concrete/pink-granite paving. Inspected local files are `artifacts/local/robson-realism-reference/tclf-robson-2019-060.jpg` and `vag-official-robson-exterior.jpg`; the latter also shows restrained warm rectangular paving around the gallery-facing steps. These images establish a material/layout family, not surveyed tile sizes, current replacement history or calibrated albedo. They remain reference only; no photographic site image is shipped.

The adopted 0.8 × 0.4 m rectangle is a visual estimate within an authored trial range of 0.6–0.9 m long by 0.3–0.45 m short. **That range is not measured from the photographs:** perspective prevents a defensible metric measurement here. The reference supports rectangular courses at a finer visual rhythm than the existing foreground; the 2:1 ratio, exact grid phase, aligned joints and dimensions remain reconstruction choices. Native review should judge this scale against nearby steps and people. No new dark bands, random slab colors, strong pink overlay, stains or inferred repairs are added.

## Scoped contract

`createRobsonPavingMaterial(library)` from `src/world/robson-paving-material.ts` returns one opaque `MeshStandardMaterial`, named `Robson Square — mineral paving`. Parent integration substitutes it only for the main garden terrain geometry's `add(g, m.concrete)` call, after the canopy branch returns. It does not replace planter walls, stairs, mound circulation, gallery stone, other footways or the shared concrete instance. It creates no geometry, collision, light, reflection capture or extra pass. One local material can split an existing shared batch at integration; this is not a claim of zero additional submissions.

The exact raw UV contract is `[worldX / 4, worldZ / 4]`, already generated by `robson-square.ts`. The vertex shader converts those untransformed UVs to `(X−Z, X+Z)/sqrt(2)`, matching `gridUV` and the garden axis. The grid therefore survives static batching independently of mesh translation or image repeat. Do not apply this material to default box UVs, metre UVs or the independently generated mound circulation. Sloping ground retains plan-space rectangular courses; this does not survey slope-length paving dimensions.

Joints are 4 mm wide, with 0.8 mm authored relief over a 6 mm edge transition. Color darkening is limited to 18% and fades below pixel size. Normal relief uses an analytic joint slope and only first screen derivatives; it does not differentiate an already filtered seam. No silhouette or walking height changes. These small values are appearance estimates, not construction measurements.

## Existing licensed grain and ownership

All three maps come from committed `public/textures/canada-place-paving/{color,normal,roughness}.webp`: the joint-free crop of Charlotte Baglioni / Poly Haven's [Granite Tile](https://polyhaven.com/a/granite_tile), [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Source URLs, hashes and preparation are in that folder's `SOURCES.json`. This is generic mineral grain, not a Robson stone scan. No download, new image or texture preparation is needed.

The factory requests those assets once each and clones each returned sampler wrapper, retaining its source image. It never changes or disposes the library's returned texture. Each local map repeats twice over the existing four-metre UV unit, giving a two-metre grain repeat with matching color/normal/roughness transforms. Color uses sRGB; normal and roughness remain linear data. Roughness multiplier 1 preserves the prepared approximately 0.75–0.85 map range; normal strength is 0.2, metalness and emission are zero. Calling the material's `dispose()` releases its three owned sampler wrappers exactly once. Existing library/image caching behavior is unchanged; identical URLs alone do not guarantee shared GPU storage with other materials.

The prepared mineral color map is bright, with measured linear channel means about `[0.82534,0.82514,0.82534]`; the old pavement means are `[0.21601,0.17802,0.13617]` before its existing `#b4b0a7` tint. Applying the old tint directly to the new maps would brighten the entire terrace substantially. The local `#5c5750` tint instead keeps mean linear luminance within 6% of the old substrate, while reducing its red-to-blue imbalance. This hex value is a compensation for the normalized source texture and current rendering pipeline, not a physical stone reflectance measurement. The new local color should be assessed in native daylight before acceptance.
