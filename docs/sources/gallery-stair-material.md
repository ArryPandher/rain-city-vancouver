# Gallery rear stair mineral finish

The [Gallery's official rear exterior photograph](https://www.vanartgallery.bc.ca/wp-content/uploads/2025/07/VAG_exterior_2023_15-5-edited-1.jpg), retained as `artifacts/local/robson-realism-reference/vag-official-robson-exterior.jpg`, shows a dark grey fine-grained flight distinct from the pale stone facade. The geometric riser/tread edges articulate the broad flights; there is no repeated facade ashlar pattern on every riser. Some construction seams are visible, but their exact registration is not established from this oblique image. The material could be concrete or dressed mineral masonry; the photograph alone does not establish its specification. It is a reference only, not a runtime image asset.

The ordinary `gallery-daylight-sw.png` candidate makes the existing flight very pale. Inspection of the actual code finds that `addGalleryEntryStairs` receives the named Gallery **foundation** material, rather than the separate upper-wall ashlar clone. That foundation nevertheless uses the same generic mineral pipeline with a 1.15 × .52 m wall-course shader, 8 mm seam and 8 mm normal relief. Those wall joints are inappropriate on short risers. The correction is scoped to the new stair shell; it does not change lighting to disguise the material issue.

`createGalleryStairMaterial` creates an opaque standard material with authored nominal colour `0x60615b`, roughness .96, metalness zero, normal strength .22, and a .75 m grain repeat. These are bounded visual estimates, not measured dry albedo or stone/grain dimensions. Both existing flights, their intermediate and upper landing surfaces, and their closed side/under-shell receive it. The facade foundation, stair framing/cheeks, retained cap, columns, cornice and upper wall finish retain their previous materials. Future bistro terrace geometry is outside this change.

The material reuses the existing loaded `landmarks/mineral-{color,normal,roughness}.webp` Sources through three independent sampler wrappers. The [manifest](../../public/textures/landmarks/SOURCES.json) identifies Charlotte Baglioni's Poly Haven CC0 [Granite Tile](https://polyhaven.com/a/granite_tile), cropped away from floor joints, neutralized and made seamless. This is generic mineral grain rather than a Gallery scan. No new image, source load, procedural weathering or fracture was added.

All channels use the existing tangent-plane metric geometry UVs: one UV unit per metre, repeat 1/.75, no rotation/offset. Albedo is sRGB; normal and roughness are linear data. No wall-course shader or replacement joint mask is installed. The actual geometry supplies the tread/riser boundaries, avoiding either horizontal grid stripes crossing treads or oversized vertical ashlar on short risers. Unregistered construction joints are deferred rather than painted at an arbitrary pitch.

The new material owns its three sampler wrappers and disposes them once on disposal; original foundation samplers and shared Sources remain unchanged. It adds one opaque batch, taking the unprofiled generated facade fixture from four to five draws (six with the existing profiled upper-wall ashlar). Positions, normals, index order, metric UVs, shadow flags and contact geometry are unchanged. No new render pass, reflection capture or realtime transparency.

## Checks and review

Focused tests exercise the real foundation shader and verify that only the stair material loses the wall-course code; shared source/sampler independence and disposal; source license; matching metric repeat; actual facade role assignment; exact selected stair attributes/indices versus the original pure assembly; and metric tread/riser UV lengths. Existing Gallery tests preserve source GLB replacement, sill/reveal geometry, the complete stair flight and actual full-city walking/chase-camera route.

The metric test ignores existing zero-normal/zero-area extrusion closure triangles, which have no visible tangent frame; no geometry cleanup is included in a material task. Twelve focused tests pass, with scoped strict TypeScript checking. Native acceptance is pending: compare the same ordinary Gallery pose and the close stair approach in the same selected light, looking for restrained grey mineral, clear physical risers and no facade grid. No default daylight promotion, build, browser or publication is part of this candidate.
