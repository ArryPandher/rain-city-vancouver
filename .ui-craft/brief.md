# Rain City design brief

An original desktop browser open-world game for Arry and friends. The reference is cinematic open-world games and realistic Vancouver, as explicitly requested by Arry. Prioritize driving, a readable street-level city, believable light, and minimal controls over marketing content. Brand: Rain City, Vancouver. Full-bleed real-time world with editorial title overlay; no mock screenshots.

Craft level 9, density 3 in-world, variance 7 for the title, motion 5. One signature: small cartographic coordinates and a coastline-derived mark tie the restrained HUD to the actual city.

Display: condensed bold sans. Body: system sans. Palette: charcoal, warm white, signal orange. UI does not falsely claim AAA production quality or photogrammetric accuracy. Original character, vehicles, and landmarks. Desktop keyboard and mouse. Settings, help, travel map and accessible menu buttons. Browser motion simulation does not run behind a paused menu.
